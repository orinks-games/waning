# Sound credits

Every file here is built by `tools/make_sounds.py`.

## Synthesized for Waning

Made in code with numpy and scipy, no recordings: footsteps, the sword hit,
being hurt, jump, landing, the wall, souls, an enemy dying, the gate bell,
the wane, death, rising to heaven, the slime, shade and ogre loops, the road
wind and the heaven pad. Same licence as the game.

## RPG Sound Pack, by artisticdude (CC0)

https://opengameart.org/content/rpg-sound-pack

so the source can be found again.
